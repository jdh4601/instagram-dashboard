|---|---|---|

## 가정

1. 훅 북마크 저장소는 기존 `lib/store` 패턴(json / sqlite / postgres 3중 구현)을 따른다.
2. 차트는 이미 설치된 `recharts`로 구현하고 기존 `FollowerGrowthChart`와 별개인 새 카드로 만든다.
3. 다운로드한 mp4는 워크스페이스 데이터 디렉토리에 저장하고 git에서 제외한다.
4. 각 작업은 TDD로 진행한다 (실패 테스트 → 구현 → `npx vitest run` + `tsc --noEmit` 통과).
5. 새 작업은 `main`이 아니라 `feat/profile-bio-header`(777b10b) 위에 쌓는다. main이 9커밋 뒤처져 있다.
6. 릴스 목록은 대시보드에서 `/reels` 페이지로 옮긴다. 대시보드는 헤더·개요·퍼널·차트에 집중한다.

## Success Criteria

- 사이드바에서 4개 탭 간 이동이 되고 현재 탭이 하이라이트된다.
- 릴스 카드 클릭 → 상세에서 영상 재생 + 4개 탭 분석 결과 확인.
- 훅 페이지에서 훅 추가·검색·즐겨찾기 후 새로고침해도 유지된다.
- 대시보드 차트 4개가 실제 데이터로 렌더되고 막대 호버 시 릴스 툴팁이 뜬다.
- 전체 `npx vitest run` 및 `npx tsc --noEmit` 통과.
